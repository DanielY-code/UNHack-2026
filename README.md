# Pathway Lens · Edventure edition

A clickable prototype that helps senior high school and first-year university students see where their courses and choices lead, and what to do when they hit a roadblock.

**Live demo:** deploy this repo on Vercel (or open `index.html` in any browser). No build step, no backend.

## What it does
- **Generated paths.** A path is built from the student's program (required courses by year) and their career goal. Primary nodes: courses, networking, hands-on experience. Optional side quests hang off the path.
- **Roadblocks grow new routes**, smallest change first: an alternative course → a similar degree → another major. Courses already passed carry over.
- **Branch out:** change goals or majors, add a minor, or add continuing studies after graduation.
- **Everything happens in the nodes.** Tap a node to open it in place; the companion lives in your root node.
- **Edventure layer:** companions, treasure, levels, themes and a Treasury.
- **Real data:** outcome figures from Statistics Canada, National Graduates Survey, Class of 2020 (2023).

Courses, programs and requirements are **illustrative sample data**.

State is saved in the browser (localStorage). Use "Start over" to reset.
